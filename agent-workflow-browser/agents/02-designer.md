# Home Music — 02 Designer

Overlay local do papel `02-designer`. As responsabilidades globais do papel continuam definidas pelo workflow externo.

Para o Home Music:

- leia `apps/web/AGENTS.md` e `docs/accessibility.md` quando a mudança tocar interface;
- preserve a diretriz visual “simples, ágil e funcional” e evite controles, textos ou estados redundantes;
- considere mobile, tablet e desktop; para TV, considere D-pad/teclado, foco visível, ordem de foco e distância de visualização;
- projete estados vazio, loading, erro, sucesso, desabilitado e conteúdo longo quando aplicáveis;
- não crie uma segunda fonte de verdade de estado apenas para simplificar a UI;
- não altere decisões de produto já aprovadas para “melhorar” o design sem necessidade material.
